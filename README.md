# DrakeAI (DrizzyAI)

Find a Drake song for any feeling.

DrizzyAI is a mood-based Drake song recommender. Describe how you're feeling — a specific moment, a vague vibe, anything — and it matches you to the Drake song that fits best, using AI-generated song descriptions and semantic similarity search.

## How it works

1. **Lyrics** are pulled from Genius for each song.
2. **Research** is gathered per song via Gemini with web search, covering critical reception, lyrical meaning, production style, and cultural context.
3. **Descriptions** are generated by combining lyrics and research into a rich, scenario-oriented profile for each song — capturing mood, energy, imagery, and the kinds of moments each song fits.
4. **Embeddings** are generated for every song description using Gemini's embedding model, converting each into a vector.
5. When you describe your mood, that input is embedded the same way and compared against every song's embedding using cosine similarity — the closest match is recommended.

Steps 1–4 are run offline ahead of time to build the song dataset. The live app only handles step 5, so it stays fast and doesn't re-run the full pipeline on every use.

## Tech stack

- Python
- [Streamlit](https://streamlit.io/) — app interface
- [lyricsgenius](https://github.com/johnwmillr/LyricsGenius) — lyrics retrieval
- [Google Gemini API](https://ai.google.dev/) — research, description generation, and embeddings
- PyTorch — cosine similarity comparison

## Setup

1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Create a `.env` file with your API keys:

GEMINI_API_KEY=your_key_here

GENIUS_ACCESS_TOKEN=your_key_here

4. Run the app: `streamlit run DrizzyAI.py`
